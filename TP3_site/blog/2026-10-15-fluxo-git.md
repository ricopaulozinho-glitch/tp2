Adotámos ramos `feature/*` a partir de `develop`, com *pull requests* revistos por um colega.

{/* truncate */}

```bash
git checkout -b feature/US01-adicionar-livro develop
```

Cada ramo corresponde a uma user story e cada commit segue a convenção `tipo(US##): descrição`.
