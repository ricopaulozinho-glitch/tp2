# Backlog e Scrum

O projeto segue **Agile/Scrum**. O backlog completo tem 57 user stories em 10 épicos.

| Épico | Tema |
|---|---|
| E1 | Livros (CRUD) |
| E2 | Utentes (CRUD) |
| E3 | Empréstimos e devoluções |
| E4 | Pesquisa |
| E5 | Reservas |
| E6 | Multas |
| E7 | Relatórios |
| E8 | Persistência e backups |
| E9 | Autenticação |
| E10 | Qualidade e DevOps |

## Sprints

| Sprint | Objetivo |
|---|---|
| 0 | Backlog e repositório |
| 1 | CRUD + persistência |
| 2 | Empréstimos e pesquisa |
| 3 | Documentação |
| 4 | Site |

## Exemplo de user story

> **US16** – Como bibliotecário, quero **emprestar um livro a um utente** para registar quem o tem.
>
> *Critérios:* verifica disponibilidade, limite de empréstimos e suspensão; define a data de devolução a 14 dias.
